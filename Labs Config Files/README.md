# Cisco Packet Tracer Configuration Files

This folder contains the configuration files for the 10 networking labs included in this repository.

Each `.txt` file contains the Cisco IOS commands and configurations used to complete the corresponding practical lab.

---

## ⚙️ Configuration Files

| No. | Lab | Configuration File |
|-----|-----|--------------------|
| 01 | Basic Cisco Router Configuration | `Task-01-Router.txt` |
| 03 | VLAN Configuration and Verification | `Task-03-VLAN.txt` |
| 04 | Inter-VLAN Routing | `Task-04-Inter-VLAN-Routing.txt` |
| 05 | Switch Port Security | `Task-05-Port-Security.txt` |
| 06 | Static Routing | `Task-06-Static-Routing.txt` |
| 07 | Default Route Configuration | `Task-07-Default-Route.txt` |
| 08 | DHCP Server Configuration | `Task-08-DHCP.txt` |
| 09 | DNS Configuration | `Task-09-DNS.txt` |
| 10 | Network Troubleshooting | `Task-10-Troubleshooting.txt` |

---

## 📌 Usage

1. Open the configuration file for the required lab.
2. Review the Cisco IOS commands used.
3. Open the corresponding `.pkt` file from the `Labs` folder.
4. Use the configuration commands to understand or recreate the lab.

The complete explanations, screenshots, and verification results are available in the `Documentation` folder.
