TASK 09 - DNS CONFIGURATION

Devices Used:
1. Router - 1
2. Switch - 1
3. Server - 1
4. PC - 1
5. Laptop - 1
6. Cable - Straight-Through
7. Wireless Access Point - 1

Note:
The laptop can be connected using either a wireless connection through the Access Point or a wired cable connection.


Router Config:

en
config t

int g0/0/0
ip add 192.168.11.1 255.255.255.0
no shut
exit


DHCP and DNS Config:

ip dhcp excluded-address 192.168.11.1 192.168.11.10

ip dhcp pool (any name)

network 192.168.11.0 255.255.255.0

default-router 192.168.11.1

dns-server 192.168.11.2

end
wr


DNS Configuration:

Go to Server.

Click the Services tab.

Turn ON HTTP and HTTPS.

Click DNS and turn it ON.

Enter any domain name (example: cisco.com).

Enter the Server IP address.

Click ADD.


PC and Laptop:

Go to PC/Laptop IP Configuration.

Select DHCP.

The IP address will be assigned automatically.

If required, refresh the device to obtain a new IP.


How to Verify:

Go to any PC or Laptop.

Open the Desktop tab.

Click Web Browser.

Type the domain name:

cisco.com

The website should open successfully.


CLI Verification:

From the Laptop, ping the Server IP address.

ping 192.168.11.2

The ping should be successful.
